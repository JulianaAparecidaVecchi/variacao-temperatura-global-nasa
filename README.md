# 🌍 Variação da Temperatura Global (NASA)

Este projeto apresenta uma visualização interativa de dados de temperatura global baseados em estudos da NASA (GISS), mostrando a evolução das anomalias de temperatura desde 1880 até 2019.

## 📊 Objetivo

Permitir a análise visual das mudanças climáticas ao longo do tempo através de gráficos interativos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js

## 📈 Funcionalidades

- Gráfico de variação da temperatura global
- Filtro por ano
- Exibição de anomalias (maior e menor valores)
- Top N extremos
- Médias móveis por período
- Interface responsiva

## 🎨 Interface

O projeto utiliza uma identidade visual inspirada na NASA, com cores azul e vermelho e layout no estilo dashboard.
